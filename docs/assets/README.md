# Assets and credits

All website assets are local under `public/assets/`. The layout has dedicated mobile background artwork; retain these files when changing desktop artwork.

| Folder         | Contents                                                                          |
| -------------- | --------------------------------------------------------------------------------- |
| `backgrounds/` | Generated Mughal architectural scenes, menu art, footer art and mobile variations |
| `branding/`    | Existing Sufi Palace wordmark and generated heritage WhatsApp emblem              |
| `food/`        | Generated biryani and kebab illustrations, disclosed as illustrative on the page  |
| `photos/`      | Restaurant photographs and the user-provided storefront reference                 |
| `logos/`       | Zomato, Swiggy, Tripadvisor and District platform logos                           |

Restaurant photograph source and in-page credit: [Wiki Kolkata](https://www.wikikolkata.com/english/food/sufi-palace-a-mughlai-food-rolls-stop-in-the-heart-of-college-street/).

Video references: [restaurant visit](https://www.youtube.com/watch?v=TVSvg5HDDxs) and [biryani film](https://www.youtube.com/watch?v=9IzQ9IJrxMc). The second is an external link because embedding was unavailable.

Review excerpts and platform buttons link to their original listings in `public/index.html`. Rating counts in `public/js/app.js` are an October 2026 snapshot and should be refreshed manually when needed. Completed order totals are not represented.

Platform marks remain the property of their respective owners. Keep the original photo credits and the Three.js license at `public/vendor/THREE-LICENSE.txt` when redistributing the project. This project does not grant additional rights to third-party photographs or marks.

`docs/references/` preserves the menu design reference and unused Blinkit logo without shipping them as public website files. Blinkit is not shown as an available ordering platform because a restaurant listing was not verified.

The WhatsApp emblem was generated with the built-in image generation tool. Its final prompt is in [whatsapp-generation.md](whatsapp-generation.md).
